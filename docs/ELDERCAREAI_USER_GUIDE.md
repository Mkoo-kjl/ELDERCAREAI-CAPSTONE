# ElderCareAI User Guide

The current screen by screen guide is [ElderCareAI User Guide](ELDERCAREAI_USER_GUIDE_UPDATED.docx). It contains 24 figure placeholders with the screen to capture and numbered operating instructions below each figure.

Capture, in order: website APK download; phone APK installation; Galaxy Watch6 preparation; monitoring and notification permissions; sign in; caregiver and patient setup; watch connection; watch monitoring; dashboard; vitals; vital detail and stable Elle insight; analytics; health history sync; live location and safe zone; medications; prescription review; appointments; care schedule; alerts and notifications; SOS and emergency contacts; Elle; settings and exports; administrator overview and accounts; administrator monitoring and reports.

Install the Android phone app through [the ElderCareAI website](https://eldercareai-capstone.vercel.app/). Its installation section links to the project team's supplied Google Drive APK. The separate Wear OS companion must also be installed on Galaxy Watch6 for watch readings. Start monitoring controls normal hybrid location collection. Safe-zone alerts accept qualifying GPS, fused and network estimates; the guide explains the confirmation delay, reported accuracy and phone-assisted location limitation.

Use real demonstration data and conceal names, phone numbers, medical notes and exact home coordinates before adding images to a report. The gray figure boxes in the Word guide are placeholders to replace with screenshots from the installed app or web portal.
