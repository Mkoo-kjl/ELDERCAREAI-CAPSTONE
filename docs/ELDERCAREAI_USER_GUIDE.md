# ElderCareAI User Guide

The current screen by screen guide is [ElderCareAI User Guide](ELDERCAREAI_USER_GUIDE.docx). It contains 20 figure placeholders with the screen to capture and instructions below each figure.

Capture, in order: sign in; caregiver and patient setup; watch connection; watch monitoring; dashboard; vitals; vital detail; analytics; health history sync; live location and safe zone; medications; prescription review; appointments; care schedule; alerts and notifications; SOS and emergency contacts; Elle; settings and exports; administrator overview and accounts; administrator monitoring and reports.

Use real demonstration data and conceal names, phone numbers, medical notes and exact home coordinates before adding images to a report. The gray figure boxes in the Word guide are placeholders to replace with screenshots from the installed app or web portal.
