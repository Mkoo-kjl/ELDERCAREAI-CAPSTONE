# ElderCareAI website

Open `index.html` directly in a browser. The landing page is static and separate from the Expo app.

## Team photos

The three team cards deliberately show photo placeholders. To add portraits later, place `kristoffer.jpg`, `melvence.jpg`, and `john-wayne.jpg` in `assets/team/`. Add the corresponding `<img src="assets/team/..." alt="...">` inside each `.team-photo` element in `index.html`; the existing CSS fills the photo area. The initials remain behind the photo as a fallback.

## Contact details

The supplied addresses ended with `@gmail`. The site uses `@gmail.com` so the email links work. Confirm these addresses before publishing.

## Images

The logo, favicon, Fitbit Inspire 3 photo, and Inter font files are copied from the app's existing assets/dependencies. The two hero photographs were created with the built-in image generation tool for this website. Their prompts describe a candid Filipino older adult and caregiver in a softly lit home, with the people on the right in the desktop composition and lower in the mobile composition so the page title remains readable. The imagery is illustrative, not a photograph of a patient or team member.
